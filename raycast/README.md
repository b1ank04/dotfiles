# Raycast

Raycast discovers Script Commands from folders configured in the app; the
`Brewfile` installs Raycast but does not restore these settings.

In Raycast Settings → Script Commands, add this checkout's `raycast/scripts`
folder. Assign `Option+T` to **Open New Ghostty**. The script requires Ghostty
at `/Applications/Ghostty.app`.

Space navigation uses the native macOS `Control+Left` and `Control+Right`
shortcuts, not Raycast scripts.
